# Vua Tiếng Việt Online
Game nhiều người chơi qua điện thoại, dùng mã phòng 5 số.
## Chạy thử
1. Cài Node.js 18+.
2. Mở terminal trong thư mục này.
3. Chạy `npm install`
4. Chạy `npm start`
5. Mở `http://localhost:3000`.
## Đưa lên Internet
Deploy thư mục này lên dịch vụ Node.js hỗ trợ WebSocket/Socket.IO. Lệnh start: `npm start`.
